# 3D → 平面：图案的第一来源

> **本工坊的默认画法：先建模，再平面化。**
> 需要图案、插画、图标、装饰元素、剪影、等距小景时，**首选 3D 建真几何，渲成透明图，再平面化**——
> 而不是用 `draw_shape` / `path.create` 一根锚点一根锚点地"画"。
>
> 工具链：`scripts/proc-mesh.py`（有机物几何）/ `layer.new3dPrimitive`（规则几何组合）/
> `layer.newModel`（客户模型） → `render-frame --transparent` → 位图直接用 或 `imageTrace` 转矢量。

---

## 一、为什么这样更省更好

手绘矢量的问题不是"不够努力"，是**模型的空间控制很弱**：曲线抖、透视错、比例失真，而且每改一次都要
重新猜坐标。3D 的透视、遮挡、投影、体积是**算出来的**，改一个字就换一个角度。

而且这条路把最贵的事情交给代码：**一个噪声函数给 8 万个顶点各一个位移**，换成矢量笔你得手拉 8 万个锚点。

一句话：**能算的不要画，能渲染的不要描，能置入的不要重画。**

---

## 二、什么时候走这条路

| 你要的 | 走法 |
|---|---|
| 图案 / 插画 / 装饰元素 / 剪影 / 图标型母题 | **3D 建模 → 平面化（本文件）** |
| 产品 / 包装 / 等距结构 / 爆炸图 / 立体字 | **3D 建模 → 平面化（本文件）** |
| 有机物（水果、石头、织物褶皱、植物） | **程序化网格 → 平面化** |
| 只有一个几何形状（矩形、圆、线、箭头、分隔线） | 直接用矢量画，别绕 |
| 文字、字距、版式、表格 | 矢量（文字永远归排版层） |
| 照片级人物 / 真实场景 / 复杂材质（皮肤、金属划痕） | `generate_image`，不要用 3D 硬扛 |
| 客户给了模型 | 用客户的，直接导入 |

**素材站的图效果不好（画质差、风格不对、构图不可控）→ 回到 3D 自己搭，不要凑合。**

## 三、四步

### 1. 建模（三种，按对象选）

| 对象 | 做法 |
|---|---|
| 有机物、需要表面起伏 | `python scripts/proc-mesh.py --preset orange --out …` （详见 `procedural-mesh.md`） |
| 规则体、几何组合、图标型母题 | `layer.new3dPrimitive` 拼装：几个 cube/torus/cylinder 叠出结构，靠 **体块关系** 而不是贴图说话 |
| 客户/外部模型 | `layer.newModel` |

**图形化母题的诀窍**：不要做一个"逼真的东西"，做一个**结构清楚的东西**。
三个圆柱拼成一只杯子、一堆方块拼成一座城，平面化之后就是一套图标语言。

### 2. 打光（决定它像"设计"还是像"渲染图"）

这是最容易翻车的一步。默认的三点布光 + 高光会让结果**像 Blender 练习**，跟平面设计格格不入。
按你要的图形语言选一种：

| 风格 | 灯光配方 | 出来的样子 |
|---|---|---|
| **无影平光**（最像扁平插画） | 只放 `Ambient` 60–90，不要 Spot | 几乎没有明暗差，只剩轮廓与色块 |
| **双色硬光**（最多用） | `Ambient` 15 + 一盏强 `Spot`（200–300，coneFeather 小），另一盏只做边缘（80–120） | 一个亮面 + 一个暗面，像丝网印的两三色 |
| **剪影 / 负形** | 关掉所有灯，把主体渲成纯色，或渲一个 alpha 遮罩 | 用于反白、套色、印章式图形 |
| **体积感**（要质感时才用） | Ambient 20–30 + key 230 + rim 130 | 有立体感，但已经接近"渲染图"，少用于纯平面稿 |

判断标准只有一条：**平面化之后，这张图放进版面像不像人画的图形？** 像渲染图就压平。

### 3. 出帧

```powershell
& $fx render-frame --project $proj --comp hero --frame 0 --transparent --out "designs\<slug>\3d\hero.png"
```

- **要 trace 成矢量**：长边 **1200–1500 px** 就够。`imageTrace` 对超过 1500 px 的图会变慢并**自动降采样**（返回 `warnings` 会说明），
  出了 4000 px 再 trace 是白花时间。trace 完是矢量，可以任意放大。
- **要直接当位图**：按最终印刷尺寸出（300dpi：px = pt × 4.1667）。
- 机位想"正投影"感：用长焦（85–135mm）并把相机拉远，透视变形会接近正交。
- 等距小景：相机 `preset='50mm'`、俯角固定，三个轴向等角，不要歪。

### 4. 平面化（三条路径，按交付物选）

**A. 位图直用**（最快）

透明 PNG → PhotoCraft 调色/阈值/色调分离（`image.adjustments.levels`、`filter.threshold` 类命令）→ `file.place` 进版面。
适合：屏幕稿、单色套印、只需要一个色块的图形。

**B. 转可编辑矢量**（要改色、要印刷、要再变形时）

进 VectorCraft，先把图 `file.place`，再：

```json
{"command":"imageTrace.makeAndExpand","params":{
  "preset":"6 Colors",          // 或省略 preset，用 params 精调
  "params":{"mode":"color","colors":3,"paths":85,"corners":80,"noise":6,
            "ignoreWhite":true,
            "keepColors":["#1F3A5F","#2E6F8E","#E2542B"]}
}}
```

- **文档尺寸必须等于出帧像素尺寸**（1400px 的图就建 1400×1400pt 的画板）。
  `file.place` 的 `width` 只影响显示，**trace 出来的路径是按原图像素坐标生成的**——
  画板开小了，路径会直接溢出。要别的尺寸就 trace 完再整组缩放。
- `mode`：`color`（彩色图形）/ `grayscale` / `blackAndWhite`（单色剪影）/ `logo`（平涂标志型）
- `colors`：2–256。**平面稿一般 3–8 色就够**，色数越多越像照片、越难改
- `paths` / `corners` / `noise`：路径精度 / 拐角保留 / 忽略掉小于 noise px 的碎块
- `ignoreWhite: true`：白色留空 → 直接压在任何底色上
- **`keepColors`：要精确品牌色就传它**，否则 trace 会把颜色就近量化（实测 #1F3A5F → #1b3354）
- 先 `imageTrace.presets` 看有哪些预设名，再决定用预设还是精调
- 返回的 `warnings` **必须读**（图像过大被降采样、`keepColors` 没匹配上等）

> 实测（1400×1400 出帧，3 色）：`{"anchors":93,"colors":3,"paths":4,"warnings":[]}`，
> 一个"三根柱子 + 一个太阳"的母题转成 4 条路径、93 个锚点、约 4 KB SVG。

转完之后：每个色块是独立路径，可以改色、改形、做 `pathfinder`、做专色。

**C. 双色 / 专色印刷**

出帧 → 阈值化 → trace `mode: "blackAndWhite"` → 得到单色轮廓 → 在 CMYK 文档里填专色值。
适合：丝网印、Riso、双色海报。

## 四、图案化（要重复排列时）

1. 建模一个"单元"（一个花、一个几何体、一个小场景）。
2. 正对机位渲染 + 透明出图。
3. trace 成矢量后，用 `pattern.*` 或手工阵列排成重复纹样；
   位图则用 PhotoCraft 做无缝拼贴（边缘接缝要检查，放大看一遍）。
4. 验收：**缩小到拇指大小时还认得出是什么**；认不出说明细节太碎，减少元素、加大对比。

---

## 五、验收（四条，缺一不可）

1. **轮廓关**：放大看主体边缘——不是完美圆/完美方（那是图元味），有明显的形体变化。
2. **图形关**：平面化后看起来像"设计出来的图形"，不是"渲出来的 3D 图"（高光、塑料反射是失败信号）。
3. **边缘关**：trace 后没有锯齿、没有断线、没有把该通的负形堵死。
4. **色数关**：印刷稿的色数是你能说清并由 CMYK 值控制的，不是"trace 出来一堆近似色"。

## 六、坑

| 现象 | 原因 |
|---|---|
| 平面化后还是"3D 渲染味" | 灯光没压平（还有强高光/反射）；改无影平光或双色硬光 |
| trace 慢 / 结果糊 | 出帧超过 1500 px 被自动降采样；重出 1200–1500 px |
| trace 出几百个碎色块 | `colors` 给太多、`noise` 给太小。平面稿 3–8 色、noise 8–20 |
| 转成矢量后改色很痛苦 | 用了 `mode: color` 但没 `ignoreWhite`，白色也被转成了色块 |
| 边缘有一圈脏边 | 出帧时主体带抗锯齿半透明像素；trace 前在 PhotoCraft 里把 alpha 硬边化 |
| 图案放大后排不对 | 先 trace 再阵列；位图先放大再 trace 会直接糊 |
| trace 出来的路径溢出画板 | 画板尺寸 < 出帧像素尺寸。`file.place` 的 width 不改变 trace 的坐标基准 |
| 转完颜色变了（品牌色不准） | trace 会就近量化。传 `keepColors` 锁定精确色值 |

---

## 七、别过度使用

3D 是**图案的第一来源**，不是"什么都用 3D"。下面这些仍然直接画：

- 文字、字距、行距、段落（文字归排版层，永远不进 3D）
- 网格线、分隔线、箭头、标注、表格
- 纯色块与简单几何（矩形、圆、多边形）——画比建快十倍
- 照片级人物与真实场景（用生图）
