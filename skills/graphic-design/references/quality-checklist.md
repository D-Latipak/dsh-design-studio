# 交付前检查清单

渲染出 PNG、用 `read_image` 看过之后，逐条打勾。任何一条不通过就修，修完重新渲染。

**这份清单只查两件事：稿子有没有硬伤，用户的要求有没有全部落实。它不评判风格。**
配色多少、留白多少、字号比例、版式手法、放几张图——都由用户的要求和 `style-dna.md` 决定，
不在这张单子的判断范围内。用户明确要的东西，即使不符合这里的某条经验，也以用户为准。

## 结构

- [ ] 1. 画布尺寸与用途匹配（对照 `format-presets.md`），没有把 A4 做成 A3。
- [ ] 2. 底色/底图铺满画布（印刷品铺到出血），边缘没有意外白边。
- [ ] 3. 元素落在版心或网格上，左右边线对齐有理由。
- [ ] 4. 元素间距成系统，没有 3 pt 这类手滑值（用户要求不规则排布时除外）。
- [ ] 5. 页面没有空文本帧、孤儿对象、屏幕外被遗忘的元素。

## 层级与可读性

- [ ] 6. 读者能排出第一、第二、第三阅读顺序（按 `style-dna.md` 的层级设定，不按固定倍数）。
- [ ] 7. 文字与底色的对比足以读清；**用户有意做低对比实现某种效果时，以用户为准**，并在交付说明里记一句。
- [ ] 8. 正文尺寸与用途匹配（印刷/屏幕/户外），没有被压缩到看不清。
- [ ] 9. 文字没有被裁切、没有溢出到帧外（`inspect_document` 无 overset）。
- [ ] 10. 中文字体正常渲染，无方框/豆腐块/缺字。
- [ ] 11. 行宽与断行合理；如果有意排成密排/长行，是用户要的或 DNA 里的。

## 视觉质量

- [ ] 12. 装饰元素不抢主体（除非用户要的就是装饰压过内容）。
- [ ] 13. 对齐逻辑统一，或不同对齐各有理由。
- [ ] 14. 缩略图下主要信息仍可读，结构仍成立（用户要的极简/低信息量除外）。
- [ ] 15. 没有明显的意外失衡（重心偏一侧、上重下空、角部杂物）——"有意的不对称"不算。

## 交付

- [ ] 16. 导出文件齐全：源文件 + `.png` 预览（长边 ≥ 2000 px）+ 需要的 `.pdf`；路径都在 `designs/<slug>/` 下。
- [ ] 17. 交付说明写清：尺寸/出血、配色（含色值）、字体、设计意图、已知假设（如缺 logo、用占位文字）、2–3 条可改方向。

## 需求落实（最重要的一节）

- [ ] 18. 打开 `brief-lock.md`，**每一条 R0N 都能在画面里指到具体位置**，并有证据（元素/参数/截图区域）。
- [ ] 19. **否定型要求**（"不要 X"）已核对：画面里没有 X。
- [ ] 20. 任何与用户原话不一致的改动，都**事先问过用户并得到同意**；没有"先做了再说"。
- [ ] 21. 用户没说的部分，假设都写在决策单和交付说明里，方便他一句话推翻。
- [ ] 22. 没有用你的偏好替换用户的选择；有分歧的地方，交付说明里保留了用户的版本和他的原话。
- [ ] 23. 参考图没有进入成品；致敬之处已在交付说明里点名作者与来源。

## 素材（有素材时查）

- [ ] 24. 每张素材都有 `manifest.json` 记录（来源/许可/尺寸）；CC BY / CC BY-SA 已署名。
- [ ] 25. 分辨率够：置入图 `effectivePpi` ≥ 300（印刷）或 ≥ 2× 目标像素（屏幕）；AI 图已落盘为文件。
- [ ] 26. 素材干净：无假字、无水印、来源不明的一张都没有。

## 字形与字艺（只有做过改造字才查）

- [ ] 27. 主标题的字形处理能用一句话说清（「把山的第三笔拉长成地平线」），不是「加了个效果」。
- [ ] 28. 缩略图下可读，或已明确做成抽象图形并配小字；字内填图有足够对比。
- [ ] 29. 转曲前留了原始字（隐藏层或 `-type` 副本）；用户明确不要时，交付说明写了「已转曲、不可逆」；
    字体许可允许改造，`CREDITS.md` 写了字体名、版本、许可与改造说明。

## 专业度加分项（有余力再做）

- 给主标题做光学对齐（标点悬挂、边角对齐）。
- 信息区的数字用表格/等宽对齐。
- 为同一设计准备一个「变体」：换主色或换版式方向，让用户有比较。
- 印刷稿附 `validate-pdf` 校验结果。

## AI 装饰小字（用户没要求时 = 必须删）

- [ ] 画面顶部/底部没有自作主张的小字英文行：kicker / eyebrow / 副标题 / 版权线 / `EST. 20XX` /
      `COLLECTION NO.01` / 城市名·坐标 / 假说明文字。
- [ ] 这类小字确实服务 brief 时才保留，而且内容来自用户给的信息（时间、地点、主办方），不是模型编的。
- [ ] 想加但用户没提 → 先问；用户点名要 → 照做并写进 `brief-lock.md`（R 编号）。
