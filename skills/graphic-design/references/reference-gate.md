# 参考关（Reference Gate）

> 一句话：**新稿必须联网搜参考图 → 逐张全面精读 → 把参考交付给用户过审 → 才能进入设计决策与排版。**
> 文件不在 = 环节没做：`designs/<slug>/refs-approved.md` 存在之前，**不许**写设计决策单、不许开三方向门、
> 不许建画布、不许排任何版。
>
> 上下游：怎么找、怎么判断「找错了」、DNA 卡模板 → `reference-hunting.md`；参考过关之后的方向选择 →
> `directions-gate.md`。本文件管四件事：**数量门槛 / 精读深度 / 交付过审 / 静默时钟**。

---

## 一、什么时候必须走

**100% 触发**：任何会产出新视觉设计的任务——海报、封面、社媒图、Banner、长图、信息图、logo、图标、
传单、菜单、邀请函、画册、界面稿、多页首版。**包括用户已经指定风格或品牌**：指定风格收窄的是解释空间，
不转移「先看真参考再动手」的义务。

**豁免（必须落字，写进 `refs-approved.md` 的「豁免」行）**：

1. 用户本次会话明说跳过参考（原话逐字记录；**联网这一步仍尽量做**，只是可以不走交付过审）；
2. 同一项目参考关已过、只是迭代改稿（沿用旧 `refs-approved.md`，不重复摆）；
3. 纯机械操作（改错字、换导出格式、修越界、按已有方向做尺寸适配）。

「用户说继续」只授权进入下一步，**不是**跳过本关；跳过必须用户明说「不要参考 / 直接做」。

> **联网是默认硬门槛**。环境自检发现 `reference_status` / 参考板脚本不可用时，先按第九节重试；重试仍失败，
> 必须在过审消息里写明「本次联网失败」，让用户决定等网络还是降级——**不许静默降级**。

## 二、数量与来源门槛（硬下限）

| 项 | 门槛 | 说明 |
|---|---|---|
| 张数 | **≥ 4 张，建议 6 张，上限 8 张** | 少于 4 张无法做交叉分析；多于 8 张精读会变成流水账 |
| 来源类型 | **不限** | 全球互联网上任何真实存在的设计/图像都算：设计站、社交平台、品牌官网、档案馆、旧物照片、影视截图、展览现场……来源只影响可信度，不是门槛 |
| 来源分散 | **≥ 2 个不同来源或 ≥ 2 组检索词** | 同一来源一个关键词抓 6 张 = 一个视角，不算参考面 |
| 画质 | 宽 ≥ 1200px 优先；600–1200px 会被收为「低清备选」，不足 4 张时自动补位（精读里标注「低清」即可） | 太小的图看不清字距，换图或只借结构 |
| 记录 | 每张有 `pageUrl` + 作者 + 年代（缺失写「未标注」） | `refs.json` / `REFS.md` 里必须有，没有记录等于没参考 |
| 对照 | 至少 1 张「同媒介」+ 1 张「跨年代 / 跨地域」 | 只收同一语法的图，会把自己锁死在一个模子里 |

**只排除"不是设计的东西"**：教程截图、模板商店页、图库带水印样机、搜索引擎结果页的缩略图、
AI 生成图（学不到可靠结构）。**参考不需要版权**——它不进成品；只有进成品的图才走素材许可流程。

**不够 / 不对怎么办**：换更具体的词（movement + medium + decade）→ 换来源 → 用 `reference_search` 的 `url`
参数喂你找到的页面/直链。最多 3 轮；仍不够就**如实说缺口**，让用户决定补图还是降级，不要凑数。

## 三、全面精读（学的是语法，不是看个热闹）

> 参考关的核心不是「找到图」，是**把图读成可执行的设计参数**。只看 `board.png` 缩略图就写 DNA 卡 =
> 没做精读，会被当成没看。

**读法（每张都要做）**：

1. `read_image` 看 `board.png`，建立整体印象与第一轮筛选（年代 / 媒介 / 类别不对的删掉）；
2. 逐张 `read_image` 看 `img/NN.jpg`——看网格线、字号跨度、留白、字距、色块边界；
3. 关键图看**局部**：用 `New-ContactSheet.ps1 -CellWidth 1600` 拼 2–3 张放大对照，
   或用 `pwsh` + System.Drawing 裁出标题区 / 信息区 / 角落再 `read_image`；
4. 边看边记**数字**（比例、色数、字号倍率、留白率），记不出的写「看不清」——**不许编**。

**每张一张「参考精读卡」**，写进 `designs/<slug>/reference-study.md`（**7 条，不是 11 条**，模板见第四节）。
字段多不等于精读：以前要求 11 条，结果每条写成一句空话，正文却贵了 3 倍。

1. 语法定位：运动 / 流派 + 年代 + 地域 + 印刷方式
2. 网格与比例：栏数 / 版心 / 边距 / 画面比例
3. 层级与字号跨度：主 / 副 / 正文的视觉倍率（如 4.8×）
4. **字体与图文关系**：字体分类与字重、图占比、图字重叠方式、留白率
5. 色彩：色数 / 主色占比 / 强调色出现次数 / 明度结构
6. **母题与工艺**：编号、细线、网点、套色错位、裁切；附一句节奏（哪段最挤、哪段最空）
7. **可迁移与不学**：可迁移规则 2 条（带数字，能直接写进命令参数）+ 不学不抄 2 件（防照抄）+ 它对应哪条需求 `R0N`

> **本文件是参考关的唯一事实源。** 其他文件（`style-research.md` / `reference-hunting.md` / `material-pass.md` `image-prompt-recipes.md`）
> 若与本文的数量、像素、字段口径不一致，**一律以本文为准**，并顺手改掉那边。

**交叉分析（全板一张表）**：

- 共性 3 条：这几张都这么做、且和本单需求一致的地方；
- 差异 3 条：它们彼此不同、可以拿来分方向的地方；
- 打架 1 条：两个参考互相矛盾时**选谁、为什么**（按受众 / 媒介 / 调性判，不按好看判）。

**DNA 卡逐字段溯源**：`reference-hunting.md` 第 4 步的 10 字段 DNA 卡，每个字段后面标注来自哪张板
（`#01`、`#03`）；**没有来源的字段就是不成立**，删掉或补查。

**完成度自检（全过才允许交付过审）**：

- [ ] 每张参考 7 条都有内容（数字或「看不清」），没有空白项
- [ ] 至少 2 张写了「不学 / 不抄 2 件」
- [ ] 交叉分析 3 共性 + 3 差异 + 1 打架
- [ ] DNA 卡 10 个字段全部带 `#NN` 溯源
- [ ] 明确标出「反例」是哪张、为什么只当反例
- [ ] 全程没把参考图当成素材（没有 `file.place`、没有描图）

## 五、交付过审（Reference Gate 的动作）

参考关不是把文件存进硬盘，是**把参考摆到用户面前，等一句准话**。交付 = 四件一起给：

1. `board.png`（编号拼版，整板一次看全）；
2. 逐张图（`![#01](绝对路径)` 或清晰的编号链接）；
3. `REFS.md` + `reference-study.md` 的路径（精读结论要能被查）；
4. 对话里 3–6 行摘要 + `style-dna.md` 摘要 + 明确的过审问题。

> 素材板（`materials-board.png`）**不再要求随参考板一起交**：要不要备素材、备几张，由用户要求和内容决定（章程 §1.8）。
> 如果你已经备了候选素材，可以顺手一起摆出来；没备也不影响参考过审。

**消息模板（照此发，别只丢一个路径）**：

```markdown
【参考过审 · <slug>】<N> 张（内置四站 / -Url 来源 X 张，馆藏 Y 张）

![参考板](<绝对路径>\designs\references\<board>\board.png)

1. #01 <标题> — <作者/年代> — <来源> — 借：<一条规则>
2. #02 …
3. #03 …

素材（如已备）：![素材板](<绝对路径>\designs\<slug>\materials-board.png)
M01 主视觉（AI/CC0，已 PhotoCraft）｜M02 底纹（CC0 纹理）｜M03 备选

精读结论：<共性一句>；<差异一句>；<打架处与我的取舍一句>
精读全文：<绝对路径>\designs\<slug>\reference-study.md

请给我一句准话：
A. 全部通过，按这个做
B. 换 / 补某张参考或素材（说编号 + 想要什么）
C. 换关键词重抓
D. 我直接给你参考链接

默认：<10> 分钟内没回复，我按 A 通过 #01–#0N 继续，记为 silent-approve，之后随时可推翻。
```

**硬规则**：

- 交付的必须是**编号可指认**的图（`New-ReferenceBoard.ps1` 已带编号标签）；用户说「第 3 张不行」要能对上；
- 没有回复 → 走第六节静默时钟，**不要**反复追问、不要连发多条；
- 用户回复后：先把原话逐字写进 `refs-approved.md`，再动下一步；
- 用户说「都不对」→ 回到第二节重抓，最多 3 轮，并在新消息里说明「第 N 轮」；
- 用户只通过一部分（「1 和 3 可以，4 太老了」）→ `partial`，换掉其余，用通过的部分做 DNA 卡。

## 六、静默时钟（用户太久没回 → 自动继续）

> 目的：参考关不能变成「等用户」的死锁。**摆出来 → 设一个到点自动继续的定时 → 结束这一回合。**

**默认参数**：等待 **10 分钟**（用户说赶时间用 5 分钟；最多 15 分钟）。到点后按**默认通过范围**继续：
默认范围 = 你在交付消息里点名的 `#01–#0N`（通常是全部设计源参考）。

**实现（按可用性取第一条，并把 `mode` 记进 `refs-gate.json`）**：

1. **`schedule_create`（首选，一次性唤醒本会话）**

   ```text
   title: 静默时钟 · <slug> · 参考过审
   target: this_session
   rrule:  DTSTART:<UTC 到点时间，形如 20261106T133000Z>
           RRULE:FREQ=DAILY;COUNT=1
   prompt: 【静默时钟到点 · <slug> · 参考过审】用户 10 分钟内未回复。
           先查 designs/<slug>/refs-approved.md：已存在 → 只删除本定时任务，不做别的；
           不存在 → 写 refs-approved.md（判定 silent-approve，通过 #01–#0N，记录时间），
           在回复开头用一句话告知用户「到点没回，我先按默认参考集继续，随时可推翻」，
           然后进入设计决策单与三方向门。不要重复追问参考。
   ```

   拿到 taskId 后写进 `refs-gate.json`。到点消息发出后，若你仍在同一回合等待，说明用错了模式——
   **参考关这一停必须结束回合**，不要用阻塞式提问占着回合。

2. **没有 `schedule_create`（工具不存在或调用失败）**：改用 `ask_user_question` 阻塞等待，
   并在消息里说明「需要你回一句才能继续」。此时**没有自动继续**，不能假装有。

3. **连提问工具也没有**：按墙上时钟续跑——下次会话恢复时若 `refs-approved.md` 不存在且
   `refs-gate.json.deadline` 已过，写 `silent-approve` 后继续，并在回复里说明。

**用户提前回复时**：

1. 先 `schedule_list`，按 title 里含 `<slug>` 找到该静默时钟任务，`schedule_edit` 删除；
2. 再按用户回复处理（通过 / 换图 / 重抓 / 否决）；
3. 用户回复的若是别的事，先办用户的事，参考状态保持 pending，在回复末尾**重申一次**过审请求（不刷屏）。

**时钟到点、定时消息进来时**：

1. 查 `refs-approved.md`：已存在 → 只删任务、回复一句「已收到你的过审，继续」，不要重复发板子；
2. 不存在 → 删任务（若还在）→ 写 `silent-approve` → 开头告知一句 → 继续下一步。

**红线**：

- **不许**把 silent-approve 写成「用户已认可」；用户之后说不行，按新指令重做并保留旧记录；
- **不许**为普通任务设定时，只用于「等用户决定」；
- **不许**在没设时钟、也没说明等待策略的情况下，摆完参考就消失；
- 用户明确说「先放着，等我」→ 不设时钟，按用户要求等。

## 七、门禁检查（动笔前跑一次）

```powershell
$slug = '<slug>'
$root = "designs\$slug"
$approve = Join-Path $root 'refs-approved.md'
if (-not (Test-Path -LiteralPath $approve)) { throw "参考关未过：缺 $approve。先交付参考板过审（或静默时钟到点）。" }
Get-Content -LiteralPath $approve -TotalCount 12
$refs = Get-Content -LiteralPath 'designs\references\<board>\refs.json' -Raw | ConvertFrom-Json
"参考 $($refs.count) 张"
if ($refs.count -lt 4) { throw '参考数量不足：至少 4 张。' }
if (-not (Test-Path -LiteralPath (Join-Path $root 'reference-study.md'))) { throw '缺 reference-study.md：先做全面精读。' }
```

三道全过（文件在 / 量够 / 精读在）才允许写设计决策单、建画布。
素材（`material-plan.md`）**不是本关的前置**：要不要图由用户要求和内容决定，见 `material-pass.md`。

## 九、失败与降级（写清楚，别假装）

| 情况 | 处理 |
|---|---|
| 联网不通 / `reference_search` 不可用 | 先用 `reference_status` 定位；重试（换来源、换关键词）≤ 3 轮；仍不通：在过审消息里写明「本次联网失败」，用 `designs/references/` 已有板子或你的专业判断先出参考假设，**让用户决定等网络还是降级** |
| 抓不到 4 张 | 最多 3 轮补抓；仍不够就如实报「只找到 N 张」，由用户决定是否降级 |
| 板子全是同一个来源 | 不算参考面；用 `-Url` 补其他平台或换检索词 |
| 参考和需求明显不匹配 | 宁可说「没找到对的」并请用户给链接，也不要凑数过审 |
| 用户拒绝所有参考 | 记录 rejected + 原话；换策略重抓一轮；用户坚持直接做则落「豁免」并进入下一步 |
