# Font Pack Manifest (OFL)

Vendored OFL font pack for offline design work. Source: <https://github.com/anthropics/skills/tree/main/skills/canvas-design/canvas-fonts> (commit `ca45fc4`), plus two licence files fetched from <https://github.com/google/fonts> where upstream omits them.

- Font files: 54 TTF, 5412104 bytes
- Licence files: 29 SIL OFL 1.1 texts, kept beside the fonts as `<Family>-OFL.txt`
- Families: 29. Invoke these files directly with Install-UserFont.ps1 or reference them from CSS/HTML via a relative path; no OS install is required for HTML rendering.

## Licence notes

All fonts are licensed under the SIL Open Font License 1.1. The licence text for each family sits next to its font files.

- **Do not rename** the font files (`*.ttf`): Reserved Font Name clauses in several licences forbid redistribution under a different name.
- `IBMPlexSerif-OFL.txt` and `InstrumentSerif-OFL.txt` come from the google/fonts repository because the upstream canvas-fonts directory ships only the sibling family text. They describe the same IBM Plex / Instrument Serif licences.
- Keep this manifest and the `-OFL.txt` files together whenever the font pack is copied elsewhere.
- OFL permits embedding and commercial use; it does not permit selling the fonts on their own.
